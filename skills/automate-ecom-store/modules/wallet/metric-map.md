# Where wallet balances and withdrawals are read

Dry run follows `{baseDir}/modules/ops/dry-run.md`: walk the steps, take the screenshots, write the report, and do not click Save, Submit, or Send.

Read the number on the screen or in the official export. The label you see wins over this table. Record that label in `source`, the report timezone in `timezone`, and `read_time` as the shop computer's local time. Do not click Withdraw, Transfer, or any bank-account control.

Read once per session. Do not refresh the balance page in a loop.

## Shopee Seller Wallet / My Balance

| Item | Usual place | Name on screen | Date basis |
| --- | --- | --- | --- |
| Available | Finance, My Balance, or Seller Wallet. | Available, or the balance that can be released. Confirm the header. | The page's own as-of time, shop market local time. |
| Pending | Same page. | To release, Pending, or Escrow. Confirm the header. | Same as-of time. |
| Incoming settlement | Same page or the income statement. | The next release or settlement line the page names. | The release date printed on that line. |
| Withdrawal | Withdrawal records on the same finance area. | Amount, fee, status, bank. | The row's request date. |

## TikTok Shop Balance / Finance

| Item | Usual place | Name on screen | Date basis |
| --- | --- | --- | --- |
| Available | Finance or Balance. | Available balance. Confirm the header. | The account timezone printed on the page. |
| Pending | Same page. | On hold, Pending, or Unsettled. Confirm the header. | Same as-of time. |
| Incoming settlement | Settlements or statements. | The upcoming settlement the page names. | The settlement date printed there. |
| Withdrawal | Withdraw or payout history. Do not start one. | Amount, fee, status, bank. | The row's request date. |

## Lazada Wallet / Account Statement

| Item | Usual place | Name on screen | Date basis |
| --- | --- | --- | --- |
| Available | Account Statement or Wallet. | Available. Confirm the header. | The seller-centre timezone printed on the page. |
| Pending | Same page. | Pending or To be released. Confirm the header. | Same as-of time. |
| Incoming settlement | Statements. | The next payout or release line. | The date on that line. |
| Withdrawal | Payout or withdrawal history. Do not start one. | Amount, fee, status, bank. | The row's request date. |

If the menu is not on screen, stop and ask. A button named Withdraw is not a place to read a number.
