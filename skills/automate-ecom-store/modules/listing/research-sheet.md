# Competitor research sheet

Read-only notes from a browser that is **not** the store's seller profile. One row per listing you actually opened. Copy figures from the screen. Do not invent a price.

| Column | What to write |
| --- | --- |
| platform | shopee, tiktokshop, or lazada |
| rank | Position in search or in the best-seller list |
| title | Title as shown |
| title_pattern | How the title is built, in words like "brand, then product, then size" |
| keywords | Words repeated across the top results |
| price_low | Lowest price you saw for this result, as printed |
| price_high | Highest price you saw for this result, as printed |
| variants | Real variation names (size, flavour), not the title |
| image_style | Cover style: pack only, pack plus badge, infographic, lifestyle |
| selling_points | Claims the images and title repeat |
| review_complaints | Repeated complaints in recent reviews |
| source | search or best_seller |

Save the sheet under `~/.automate-ecom-store/data/listing-research/`. Do not commit it.
