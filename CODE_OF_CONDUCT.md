# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive.
- Accept feedback gracefully and focus on what is best for the community.
- Protect other people's private data — never post store data, keys, or personal details.

## Enforcement

Report unacceptable behaviour privately to the maintainers through a GitHub private security advisory or a direct message to an organization owner of `sonaecom`. Maintainers may remove, edit, or reject contributions and may ban contributors who violate this code.
